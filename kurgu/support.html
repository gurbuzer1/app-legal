The game

You never move the robot. You write the rule it follows, and the board runs that rule for you. When the painted squares match the target pattern, the level is solved.

Writing a rule

A rule is a list of lines. Each line is a condition and an action. There are six conditions — if a wall is ahead, if the square ahead is painted, if the square ahead is clear, if the square under me is painted, if the square under me is clear, and always — and five actions: move, turn right, turn left, paint, stop.

Two things decide everything. A rule may have at most four lines, and no condition may appear twice. On each step the robot runs the first line whose condition is true, so the order you put the lines in is part of the puzzle.

Why did the run end?

A run finishes in one of five ways, and the game names the one that happened:

  • Pattern completed — the only one that wins.
  • The robot stopped itself — a stop action ran.
  • The robot didn't know what to do — no line's condition matched. Adding an always line at the bottom is the usual fix.
  • The robot got stuck in a loop — it returned to a state it had already been in, so it would repeat forever.
  • Step limit reached — the run was long enough to be going nowhere.

Levels are locked

There are thirty-two levels and they open in order: the next one unlocks when the one before it is solved. Every board has been checked by a solver, so there is no level in the game that cannot be finished.

My progress disappeared

The save lives on the device only. It is not backed up to any server, because the app has no server. Deleting the app deletes it, and a new device starts from the first level. There is no account to sign into and no way for me to restore a save remotely.

One thing worth knowing: the app does not take your word for a solved level. On every load it runs each saved rule again on its board, and a rule that no longer reaches the target is dropped. So if a level went back to unsolved, it is because the rule stored for it does not actually solve it — write in and I will look at the case.

How do I erase everything?

Delete the app. That removes the saved rules and everything with them. Reinstalling gives you a fresh start from the first level.
