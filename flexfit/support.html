Anything at all — a personal record that did not trigger, a workout that would not finish, a number that looks wrong, a crash — write to gurbuzer1@gmail.com. Tell me what you tapped and what you expected; that is usually enough to find it.

Where is my training log kept?

On your phone, in the app's own storage, and nowhere else. No account, no cloud. That is deliberate — but it has one consequence worth saying plainly: if you delete the app or lose the phone, the log goes with it. There is no server copy to restore from.

Is anything locked behind a purchase?

No. There is nothing for sale in this version and no price is shown anywhere. Every feature — the exercise library, custom exercises, templates, the rest timer, history and personal records — is available to everybody.

Are there ads?

No. There never have been, despite an old store description that said otherwise.

How do I start?

The app arrives with an exercise library and a few templates already in it, so you can start a workout on the first screen without setting anything up. Tap a template, then log each set as you finish it; the rest timer starts by itself between sets.

When does something count as a personal record?

When a completed set beats your previous best for that exercise on weight, on reps, or on volume (weight × reps). Any one of the three is enough. Sets you leave unticked are not counted, so a warm-up you never completed cannot become a record.

Can I change kilograms to pounds?

Settings → Weight Unit. It changes the label on every entry field; it does not convert numbers you have already logged, so switch it before you start rather than halfway through a programme.

Does it need internet?

No, and it never will. Everything happens on your phone. Aeroplane mode changes nothing.
